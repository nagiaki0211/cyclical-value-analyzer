# シクリカルバリュー株分析アプリ

書籍『50万円を50億円に増やした 投資家の父から娘への教え』(たーちゃん著、
ダイヤモンド社)で紹介されている「シクリカルバリュー株投資」の考え方を
参考にした、判断材料の可視化ツール群です。本リポジトリには2つのアプリが
含まれています。

1. **シクリカルバリュー株分析アプリ(Streamlit)** ― 個別銘柄のPSR推移や
   業績不振スクリーニングをブラウザ上で対話的に確認するツール(下記)
2. **個別銘柄・企業分析レポート生成アプリ(CLI)** ― 株探(kabutan.jp)の
   データから資産バリュー/収益バリュー/シクリカルバリューの該当判定と
   7項目評価付きのHTMLレポートを生成するツール([後述](#個別銘柄企業分析レポート生成アプリ))

> **重要な注意**
> 本アプリは**断定的な売買シグナルを出すものではなく、投資助言でもありません**。
> あくまでPSR(株価売上高倍率)や業績推移、景気サイクル位置の機械的な目安などを
> 可視化し、ユーザー自身の判断を助けるための材料を提示することを目的としています。
> 数値基準の一部(PSRの割安ゾーンの基準等)は書籍の公開情報だけでは具体的な値を
> 特定できなかったため、[要確認]として仮置きしています。サイドバーからいつでも
> 調整できます。最終的な投資判断は自己責任で行ってください。

## この投資法の考え方(概要)

- 「いま業績が良い会社」ではなく、「いま赤字・業績不振」の会社の中から将来の
  回復が期待できる銘柄を先回りして拾う、逆張り的なアプローチ。
- PER(株価収益率 = 時価総額 ÷ 純利益)は赤字企業だと算出できないため、
  代わりに **PSR(株価売上高倍率 = 時価総額 ÷ 売上高)** を主指標として使う
  (売上さえあれば赤字企業でも算出できる)。
- 景気サイクルはおよそ4年周期という前提で、「いまサイクルのどこにいるか」を意識する。
- 当たれば10倍株(テンバガー)になりうる、ハイリスク・ハイリターンな投資法。

## セットアップ手順

```bash
# 1. リポジトリを取得
git clone https://github.com/nagiaki0211/cyclical-value-analyzer.git
cd cyclical-value-analyzer

# 2. (推奨) 仮想環境を作成
python3 -m venv venv
source venv/bin/activate  # Windowsの場合: venv\Scripts\activate

# 3. 依存パッケージをインストール
pip install -r requirements.txt

# 4. アプリを起動
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 使い方

1. **個別銘柄分析タブ**
   - ティッカー(銘柄コード)を入力します。
     - 日本株: `XXXX.T` 形式(例: トヨタ自動車 = `7203.T`)
     - 米国株等: そのまま(例: `AAPL`)
   - 株価・売上高・営業利益/純利益の推移、PSRの現在値と過去レンジ、
     直近の赤字/減益フラグ、回復シナリオ用の増減率グラフ、
     景気サイクル位置の目安が表示されます。
   - 無料API(yfinance)から売上高・利益データが取得できない銘柄は、
     「業績データを手入力」から自分で入力して補完できます。
   - 気になった銘柄は「ウォッチリストに追加」で登録できます。

2. **業績不振企業スクリーニング タブ**
   - カンマ区切りで複数のティッカーを入力し、あえて直近赤字・減益が
     続いている銘柄を抽出します(一般的な優良企業スクリーニングとは逆方向)。
   - 入力リスト内での業種平均PSR(参考値)も表示します。

3. **ウォッチリスト タブ**
   - 登録した銘柄のPSR・赤字/黒字フラグ・業種・サイクル位置目安を
     一覧で比較できます。

4. **サイドバーの設定**
   - PSRの割安ゾーンの基準、想定サイクル周期(年)、山谷検出の感度、
     減益とみなす連続期間数など、[要確認]としていた数値基準を
     自分の考え方に合わせて調整できます。

## 技術構成

- 言語: Python
- UI: Streamlit
- データ取得: yfinance(無料API。取得できない項目は手入力で補完)
- グラフ: Plotly
- 山谷検出: scipy.signal.find_peaks

```
app.py              # Streamlitアプリ本体(画面構成)
config.py           # 既定の設定値([要確認]項目を含む)
lib/data.py         # yfinanceによるデータ取得
lib/metrics.py       # PSR・増減率・山谷検出・サイクル位置の計算
lib/analysis.py      # 1銘柄分の取得〜計算をまとめるオーケストレーション
lib/watchlist.py     # ウォッチリストのローカル保存(watchlist_data.json)
```

## データ取得に関する注意

- yfinanceは無料APIのため、銘柄によっては売上高・営業利益・純利益等の
  財務データが取得できない場合があります。取得できない場合はアプリ上に
  その旨を表示し、手入力で補完できるようにしています。
- 過去のPSRは、発行済株式数が現在と同じだったと仮定して時価総額を近似計算
  しています。増資や株式分割等があった銘柄では実際の値とずれる場合があります。
- 業種平均PSRは、無料APIの制約上、公式な業種指数ではなく、ユーザーが
  比較対象として入力したリスト内での平均値を参考情報として表示しています。
- yfinanceの無料範囲では年次の売上高・利益データが直近4〜5年分程度しか
  取得できません(要件で想定していた「過去5〜10年分」には届きません)。
  より長期のデータで分析したい場合は「業績データを手入力」欄から補完してください。

## 個別銘柄・企業分析レポート生成アプリ

証券コードを1つ指定すると、株探(kabutan.jp)から財務データを取得し、
「資産バリュー株」「収益バリュー株」「シクリカルバリュー株」のいずれに
該当するかを自動判定したうえで、HTML形式の企業分析レポートを生成する
コマンドラインツールです(`generate_report.py`)。

### 使い方

```bash
# 依存パッケージは上記と共通(requirements.txt に含まれています)
python generate_report.py 7203
```

`output/{証券コード}_{会社名}_report.html` にレポートが生成されます。
ブラウザでそのまま開いて閲覧できます。

### 株探(kabutan.jp)へのアクセスについて

- 株探の robots.txt が許可する範囲(`/stock/*`)のみアクセスし、
  指定されている `Crawl-delay: 3` に従ってリクエスト間に3秒以上の
  間隔を空けています。
- 個人の調査・学習目的での利用を想定しています。高頻度・大量アクセスや
  データの再配布は行わないでください。利用前に株探の利用規約をご確認ください。

### 貸借対照表の内訳の自動取得(EDINET連携、推奨)

株探の無料ページには、貸借対照表の内訳(流動資産・固定資産・棚卸資産等)や
売上総利益が含まれていません。このため、清算価値・流動比率・当座比率・
固定比率などの一部指標は、株探のデータだけでは算出できません。

この不足分を、金融庁の**EDINET**(有価証券報告書の公式開示システム)から
自動取得できます。設定は任意ですが、設定すると多くの指標が自動で埋まります。

1. 以下にアクセスし、「EDINET API」の利用者登録を行う(無料、メールアドレス
   登録のみで審査等はありません)

   ```
   https://disclosure2.edinet-fsa.go.jp/
   ```

   発行された **Subscription-Key**(APIキー)を控えてください。

2. リポジトリ直下の `.env.example` を `.env` にコピーし、取得したキーを
   設定する

   ```bash
   cp .env.example .env
   ```

   `.env` の中身を以下のように編集します(`.env` は `.gitignore` 済みで、
   GitHubにはアップロードされません)。

   ```
   EDINET_API_KEY=取得したキーの文字列
   ```

3. 通常どおり `python generate_report.py <証券コード>` を実行すると、
   自動的に有価証券報告書を検索してデータを補完します
   (初回検索には決算期に応じて数十秒かかることがあります。一度見つかった
   書類はキャッシュされ、2回目以降は高速になります)。

**対応会計基準**: 日本基準(JGAAP)・IFRS(国際会計基準)の主要企業で動作確認済み。
米国基準(US-GAAP)採用企業には対応していません。また、金融子会社を持つ会社
(自動車メーカー等)は、通常の製造業向けの資産区分に当てはまらない資産
(金融債権等)が多く、清算価値が実態より低く算出される場合があります。
その場合はレポート内に注意書きが表示されます。

### 手入力による補完(manual_data)

`python generate_report.py <証券コード>` を初めて実行すると、
`manual_data/{証券コード}.json` に入力用テンプレートが自動生成されます。
EDINET連携で自動取得できなかった項目(または未設定の場合はすべての項目)を、
有価証券報告書等を参照して手入力できます。入力後、再度コマンドを実行すると
レポートに反映されます(手入力した値はEDINETの自動取得より優先されます)。

### レポートの構成

- 基本情報・事業内容・業績推移・財務諸表の要約
- 財務指標(健全性・収益性・成長性)と危険信号フラグ
- 企業価値の目安(清算価値・DCF法・ネットキャッシュ枯渇年数)
- 投資判断(7項目×5段階評価 A〜E)
- 該当した銘柄タイプ別の着眼点セクション
- 平易な言葉でまとめた総括、専門用語の用語集

### ファイル構成

```
generate_report.py           # CLIエントリポイント
report_app/scraper.py        # 株探からのデータ取得(レート制限付き)
report_app/edinet.py         # EDINETからの貸借対照表内訳の自動取得
report_app/edinet_config.py  # EDINET APIキー(.env)の読み込み
report_app/manual_input.py   # 手入力データ(manual_data/*.json)の読み込み
report_app/metrics.py        # 財務指標・危険信号フラグの計算
report_app/valuation.py      # 清算価値・DCF法の計算
report_app/classifier.py     # 3タイプ(資産/収益/シクリカル)の判定
report_app/grading.py        # 7項目×5段階評価
report_app/summary.py        # 総括文の生成
report_app/svg_chart.py      # レポート埋め込み用の簡易グラフ
report_app/report_generator.py  # 上記をまとめてHTMLを描画
report_app/templates/report_template.html  # レポートのHTMLテンプレート
```
