# 個別銘柄・企業分析レポート生成アプリ

書籍『50万円を50億円に増やした 投資家の父から娘への教え』(たーちゃん著、
ダイヤモンド社)の考え方を参考にした企業分析ツールです。証券コードを
1つ指定すると、株探(kabutan.jp)とEDINET(金融庁)のデータから、
「資産バリュー株」「収益バリュー株」「シクリカルバリュー株」のいずれに
該当するかを自動判定したうえで、HTML形式の企業分析レポートを生成します。

> **重要な注意**
> 本アプリは**投資助言ではなく、分析のための参考情報を提供するツール**です。
> 断定的な売買シグナルを出すものではありません。表示される数値・判定は
> 公開情報をもとにした機械的な計算であり、正確性を保証するものではありません。
> 最終的な投資判断はご自身の責任で行ってください。

## 使い方(2通り)

### A. ブラウザで使う(Streamlit)

```bash
git clone https://github.com/nagiaki0211/cyclical-value-analyzer.git
cd cyclical-value-analyzer
python3 -m venv venv
source venv/bin/activate  # Windowsの場合: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。証券コードを
入力して「レポート生成」ボタンを押すだけで、その場にレポートが表示されます。

**Streamlit Community Cloudで公開する場合**(自分のPCを使わず、スマホ等
どこからでもアクセスしたい場合):

1. https://share.streamlit.io/ にGitHubアカウントでログイン
2. 「Create app」→ Repository: `nagiaki0211/cyclical-value-analyzer` /
   Branch: 使用するブランチ / Main file path: `app.py`
3. EDINET連携を使う場合は、アプリの「Settings」→「Secrets」に以下を追加

   ```toml
   EDINET_API_KEY = "取得したキーの文字列"
   ```

### B. コマンドラインで使う

```bash
python generate_report.py 7203
```

`output/{証券コード}_{会社名}_report.html` にレポートが生成されます。
ブラウザでそのまま開いて閲覧できます。

## レポートの構成

- 基本情報(株価指標は予想PER・実績PBRの基準時点を明示)・事業内容・業績推移
- 四半期業績(前年同期比・前期比・TTM)、事業セグメント別の売上高・利益
- 財務諸表の要約、財務指標(健全性・収益性・成長性)と危険信号フラグ
  - 判定は5段階(良好／標準／要観察／注意／判定不能)。業種差が大きい指標を
    単純なOK/NGで切らないため
- 株主構成・ガバナンス、定性リスク(有価証券報告書からのイベント抽出)
- 企業価値の目安
  - DCF法(弱気・標準・強気の3シナリオ。WACC・永久成長率・ターミナルバリュー・
    1株あたり価値・感応度分析まで開示)
  - 簡易修正純資産(資産別の掛け目内訳付き)、ネットキャッシュ／ネットデット
- 投資判断(6項目×5段階評価 A〜E)
- 出典・データ系統(各数値の取得元・対象期間・実績/予想・連結/単体・単位)
- 平易な言葉でまとめた総括、専門用語の用語集

## テスト

計算式・データ定義・表示ロジックの回帰テストを同梱しています
(標準ライブラリの unittest のみ。追加インストール不要)。

```bash
python3 -m unittest discover -s tests -v
```

検証している内容の例:

- 貸借対照表の整合(資産合計 = 負債合計 + 純資産合計)
- 当座比率が流動比率を上回らない(当座資産の定義)
- 弱気DCF ≦ 標準DCF ≦ 強気DCF、WACC > 永久成長率
- EV/EBITDAが構成要素から再計算できる、PER = 株価÷EPS、PBR = 株価÷BPS
- TTM・前年同期比・前期比の参照先、円/百万円/億円の単位換算
- 情報未入力の項目が最高評価にならない、見出し番号に欠番が出ない

## 株探(kabutan.jp)へのアクセスについて

- 株探の robots.txt が許可する範囲(`/stock/*`)のみアクセスし、
  指定されている `Crawl-delay: 3` に従ってリクエスト間に3秒以上の
  間隔を空けています。
- 個人の調査・学習目的での利用を想定しています。高頻度・大量アクセスや
  データの再配布は行わないでください。利用前に株探の利用規約をご確認ください。

## 貸借対照表の内訳の自動取得(EDINET連携、推奨)

株探の無料ページには、貸借対照表の内訳(流動資産・固定資産・棚卸資産等)や
売上総利益が含まれていません。このため、清算価値・流動比率・当座比率・
固定比率などの一部指標は、株探のデータだけでは算出できません。

この不足分を、金融庁の**EDINET**(有価証券報告書の公式開示システム)から
自動取得できます。設定は任意ですが、設定すると多くの指標が自動で埋まります。

1. 以下にアクセスし、「EDINET API」の利用者登録を行う(無料、メールアドレス
   登録のみで審査等はありません)

   ```
   https://disclosure2.edinet-fsa.go.jp/
   ```

   発行された **Subscription-Key**(APIキー)を控えてください。

2. ローカルで実行する場合は、リポジトリ直下の `.env.example` を `.env` に
   コピーし、取得したキーを設定する

   ```bash
   cp .env.example .env
   ```

   `.env` の中身を以下のように編集します(`.env` は `.gitignore` 済みで、
   GitHubにはアップロードされません)。

   ```
   EDINET_API_KEY=取得したキーの文字列
   ```

   Streamlit Cloudで使う場合は、上記「Secrets」に設定してください。

3. 通常どおりレポートを生成すると、自動的に有価証券報告書を検索して
   データを補完します(初回検索には決算期に応じて数十秒かかることが
   あります。一度見つかった書類はキャッシュされ、2回目以降は高速になります)。

**対応会計基準**: 日本基準(JGAAP)・IFRS(国際会計基準)の主要企業で動作確認済み。
米国基準(US-GAAP)採用企業には対応していません。また、金融子会社を持つ会社
(自動車メーカー等)は、通常の製造業向けの資産区分に当てはまらない資産
(金融債権等)が多く、清算価値が実態より低く算出される場合があります。
その場合はレポート内に注意書きが表示されます。

## 手入力による補完(manual_data、ローカル実行時のみ)

`python generate_report.py <証券コード>` を初めて実行すると、
`manual_data/{証券コード}.json` に入力用テンプレートが自動生成されます。
EDINET連携で自動取得できなかった項目(または未設定の場合はすべての項目)を、
有価証券報告書等を参照して手入力できます。入力後、再度コマンドを実行すると
レポートに反映されます(手入力した値はEDINETの自動取得より優先されます)。

※ Streamlit Cloud等のホスティング環境ではファイルシステムが一時的なため、
この手入力機能は主にローカル実行を想定しています。

## ファイル構成

```
app.py                        # Streamlit UI(ブラウザから証券コードを入力して実行)
generate_report.py            # CLIエントリポイント
report_app/scraper.py         # 株探からのデータ取得(レート制限付き)
report_app/edinet.py          # EDINETからの貸借対照表内訳の自動取得
report_app/edinet_config.py   # EDINET APIキー(.env / Streamlit Secrets)の読み込み
report_app/manual_input.py    # 手入力データ(manual_data/*.json)の読み込み
report_app/metrics.py         # 財務指標・危険信号フラグの計算
report_app/valuation.py       # 清算価値・DCF法の計算
report_app/classifier.py      # 3タイプ(資産/収益/シクリカル)の判定
report_app/grading.py         # 7項目×5段階評価
report_app/summary.py         # 総括文の生成
report_app/svg_chart.py       # レポート埋め込み用の簡易グラフ
report_app/report_generator.py   # 上記をまとめてHTMLを描画
report_app/templates/report_template.html  # レポートのHTMLテンプレート
```
